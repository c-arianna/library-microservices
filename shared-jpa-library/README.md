## Overview

The Shared JPA Library provides reusable persistence infrastructure for the Library Platform microservices.

The module centralizes common JPA-based implementations used by Event Sourcing, integration event storage and replay operations, allowing services to reuse a 
consistent persistence model while reducing duplication.

The library builds on top of the Shared Core Library and provides the persistence layer required by the platform's event-driven architecture.

## Purpose

The library provides reusable components for:

- event store persistence;
- integration event persistence;
- replay infrastructure;
- common repository abstractions;
- reusable JPA entities;
- Spring Boot auto-configuration.

## Architectural Role

The module acts as the persistence foundation for services adopting Event Sourcing.

The library is used by:

- Book Service
- Loan Service
- User Service

The module contains no business-specific logic and focuses exclusively on reusable persistence capabilities.

## Event Store Infrastructure

The library provides reusable JPA adapters for managing event streams.

Core components include:

- AbstractJpaEventRepositoryAdapter
- BaseEventJpaRepository
- BaseEventEntity

These abstractions provide a consistent implementation of event persistence and retrieval across all services.

Supported operations include:

- appending events to streams;
- loading event streams;
- event existence checks;
- event lookup;
- processed-event tracking.

## Integration Event Infrastructure

The library provides dedicated persistence support for consumed integration events.

Key components include:

- AbstractJpaIntegrationEventRepositoryAdapter

This infrastructure allows services to store and track consumed integration events while preventing duplicate processing and supporting idempotent event handling.

## Base Event Model

The library defines a common event entity model shared across services.

The base event structure includes:

- aggregate identifier;
- aggregate type;
- event identifier;
- event type;
- event version;
- schema version;
- event category;
- processing status;
- occurrence timestamp.

This approach ensures consistency across all event stores in the platform.

## Replay Infrastructure

The platform supports rebuilding projections through replay.

The library provides the `ReplayTableManager` component to support:

- temporary table creation;
- read model rebuilding;
- atomic table replacement;
- temporary resource cleanup.

This allows services to rebuild projections safely while minimizing downtime.

## Spring Boot Integration

The module provides auto-configuration support through the `SharedLibraryJpaAutoConfiguration` class.

This configuration automatically registers:

- table management utilities.

Services can integrate the persistence infrastructure with minimal configuration.

## Event Categories

The library supports persistence of two event categories:

- Producer events
- Consumer events

Producer events represent domain events generated by a service.

Consumer events represent integration events received from external services.

This distinction supports replay scenarios, idempotency and event processing tracking.
